# Banana 🍌

A fictional technology brand created as a rival to Apple for a school web-design competition.

## About

Banana is a fictional tech company with its own phones, accessories and some pretty unusual gadgets.

The website includes fictional products such as Banana Eye-Control, Banana Brain-Sensor, Banana-Flyer, an Iris Scanner, Contact-less Charger, Mind Control Headphones, Banana Phone Holder, Bluetooth Pocket Speaker and a Teddy Bear Case.

The project was made for a school competition where we had to create a rival to Apple. I wanted Banana to feel like an actual technology brand rather than just a website for one product, so I made different products and pages around the idea.
